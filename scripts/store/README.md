# Store assets

`build_play_assets.py` turns raw 1080×2400 release-build captures into the designed Google Play phone screenshots
(1080×1920) and the 1024×500 feature graphic, English and Urdu. Captions live in `captions.json`. Usage, capture list
and design notes: `docs/play-console/STORE_LISTING_v2.md` → "Screenshots and feature graphic (T5)".
